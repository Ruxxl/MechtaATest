после него может стабильно получать 0 элементов, если на странице несколько похожих
кандидатов — правильно `cy.get(selector).filter(...)`; опечатка в одну букву
("Объём"/"Объем") может выглядеть неотличимо от гонки состояний и потратить много
времени на "починку" несуществующей проблемы, если не проверить название буквально
через API в первую очередь.
