# Баги, найденные при тестировании B2B-лендингов «Корпоративным клиентам» / «Оптовым клиентам»

Дата: 2026-08-20
Стенд: `https://pp.yc.mechta.kz/` (preprod), страницы `/corporate/` и `/wholesale/`
Тест-план: `TestPlans/B2B-corp-wholesale-landing-testplan.md`

Открытых багов нет — все найденные подтверждённые дефекты исправлены (см. ниже).

## Исправленные баги (перепроверено 2026-08-20, закрыто)

- **BUG-003 (AS-4592) — В футере отсутствовала ссылка «Оптовым клиентам».** При
  перепроверке в футере (колонка «Партнерам») теперь есть отдельные ссылки
  «Корпоративным клиентам» → `/corporate/` и «Оптовым клиентам» → `/wholesale/`.
  Подтверждено DOM-проверкой (`getBoundingClientRect` внутри `<footer>`). Jira
  AS-4592 → Готово.
- **BUG-004 (AS-4596) — В хедере не было прямой ссылки «Оптовым клиентам».** При
  перепроверке верхняя строка хедера теперь содержит оба пункта — «Корпоративным
  клиентам» → `/corporate/` и «Оптовым клиентам» → `/wholesale/`, как в Figma.
  Подтверждено и DOM-проверкой (внутри `<header>`), и визуально скриншотом. Jira
  AS-4596 → Готово.

## Отклонённые находки (перепроверено / не баг)

- **BUG-001 (AS-4590) — «Форма заявки не отправляет данные».** Ложное срабатывание
  моего теста: использованный тестовый БИН («123456789012») не проходит контрольную
  сумму по алгоритму РК (веса `[1..11]`/`[3..11,1,2]` mod 11) — форма тихо отклоняла
  сабмит без видимой ошибки на поле БИН. С валидным по чек-сумме БИН
  («999123400054») форма реально отправилась, показала тост «Заявка отправлена —
  менеджер свяжется с вами в ближайшее время», запрос на `corporate-leads` ушёл
  (подтверждено пользователем скриншотом DevTools). Jira AS-4590 → Готово, файл
  удалён.
- **BUG-002 (AS-4591) — «Задвоенный заголовок секции на вкладке Оптовым».** По
  решению владельца продукта — намеренное решение, не дефект. Jira AS-4591 →
  Готово, файл удалён.
- **BUG-004 (AS-4594) — «Текст 3-го вопроса FAQ отличается от Figma».** По решению
  владельца продукта — сокращённая формулировка («физ. лица»/«юр. лица») приемлема,
  расхождение с макетом не считается дефектом. Jira AS-4594 → Готово, файл удалён.

## Что НЕ было оформлено как баг (и почему)

- **Переключатель вкладок, URL-роутинг (`/corporate/`/`/wholesale/`), карточка менеджера
  (копирование телефона/email), пустой сабмит формы (клиентская валидация всех 5 полей),
  валидация телефона (маска +7 XXX XXX-XX-XX), успешный сабмит формы с валидными данными
  (реальный POST на `corporate-leads`, тост подтверждения), FAQ-аккордеон
  на «Корпоративным клиентам» (одиночное раскрытие, реальный контент), кросс-табличный сброс
  данных формы при переключении вкладки** — всё проверено, соответствует ожиданиям
  тест-плана, багов не найдено.

## Открытый вопрос (не заведён как баг, но стоит держать в уме)

- При **невалидном по чек-сумме БИН** форма отклоняет сабмит без какой-либо видимой
  подсказки пользователю (поле БИН не подсвечивается ошибкой) — обнаружено при
  диагностике BUG-001, отдельным багом не заводилось, так как не было целью проверки
  и не подтверждено повторно как самостоятельный дефект.
