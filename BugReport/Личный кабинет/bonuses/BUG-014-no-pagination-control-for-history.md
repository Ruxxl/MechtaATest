# BUG-014: На странице «Бонусы и фишки» полностью отсутствует элемент пагинации/подгрузки — видны только первые 10 из 197 операций

**Раздел:** Личный кабинет — Бонусы и фишки (`/cabinet/bonuses/`), список операций
**Severity:** High
**Приоритет:** High
**Статус:** Подтверждён
**Дата обнаружения:** 2026-08-07
**Окружение:** `http://d2.im.mdev.kz/cabinet/bonuses/` (тестовый стенд d2), API `http://api.d.im.mdev.kz`

## Предусловия

У аккаунта 197 операций начисления (`GET
/v2/personal/bonuses-history?page=1&limit=10` → `all_items_count: 197,
all_pages: 20, page_number: 1`).

## Шаги воспроизведения

1. Открыть `/cabinet/bonuses/`.
2. Прокрутить страницу вниз до конца списка операций.
3. Проверить, есть ли кнопка/элемент подгрузки следующей страницы, или
   срабатывает ли автоматическая подгрузка при скролле (infinite scroll).

## Ожидаемый результат

Поскольку `page_number` (1) явно меньше `all_pages` (20), должен быть
доступен способ увидеть остальные записи — кнопка «Показать ещё»/пагинация
(TC-БО-33), либо автоматическая подгрузка по скроллу.

## Фактический результат

На странице отображаются ровно **10** карточек операций — и ни кнопки, ни
пагинации, ни какого-либо индикатора «показать ещё» не существует нигде в
DOM (`document.querySelectorAll('button, [role="button"]')` не содержит ни
одного элемента с текстом, похожим на «ещё»/«далее»/«показать»/«загрузить»).
После последней (10-й) карточки список сразу переходит в футер сайта
(«Скачайте приложение» / контакты). Прокрутка до конца страницы не
триггерит никакой дозагрузки.

Пользователь физически не может увидеть 187 из 197 своих операций
начисления бонусов/фишек — при том, что для сравнения на странице «Мои
заказы» (тот же раздел ЛК) кнопка «Ещё заказы» реализована и работает
корректно (см. `../orders/README.md`).

## Скриншоты

Список операций визуально обрывается на 10-й карточке (Заказ №10394388),
сразу за которой идёт блок «Скачайте приложение» — без какого-либо
элемента пагинации между ними.

## Вероятная причина

Компонент подгрузки следующей страницы, реализованный для списка заказов
(`/cabinet/orders/`), не подключён (либо не реализован) для списка операций
бонусов/фишек (`/cabinet/bonuses/`) — при том, что бэкенд-контракт
(`page`/`limit`/`all_pages`/`page_number`) идентичен и явно рассчитан на
постраничную навигацию.

## Автотест, фиксирующий баг

`cypress/e2e/main_test/cabinet/bonuses.cy.js` — тесты пагинации
(«Кнопка «Показать ещё» отображается...», «Клик «Показать ещё» отправляет
запрос со page=2») ожидают наличие элемента пагинации и падают, пока баг не
исправлен.
