# BUG-023: Фильтры «Опубликованные»/«Отклонённые»/«На модерации» на вкладке «Мои отзывы» не отрисованы вообще

**Раздел:** Личный кабинет — Отзывы (`/cabinet/reviews/`), вкладка «Мои отзывы»
**Severity:** Medium
**Приоритет:** Medium
**Статус:** Подтверждён
**Дата обнаружения:** 2026-08-07
**Окружение:** `http://d2.im.mdev.kz/cabinet/reviews/` (тестовый стенд d2)

## Предусловия

`GET /v2/reviews/personal?filter=all&page=0` отдаёт
`data.filters: [{name:"Все",code:"all",...}, {name:"Опубликованные",...},
{name:"Отклоненные",...}, {name:"На модерации",...}]` — 4 именованных
фильтра, готовых к отображению.

## Шаги воспроизведения

1. Открыть `/cabinet/reviews/`, перейти на вкладку «Мои отзывы».
2. Проверить наличие на экране 4 фильтров: «Все», «Опубликованные»,
   «Отклонённые», «На модерации» (TC-ОТ-16).

## Ожидаемый результат

На экране отображаются 4 фильтра с названиями, соответствующими
`filters[].name`, кликабельные для переключения (TC-ОТ-17).

## Фактический результат

Ни одного элемента с текстом «Опубликованные» или «Отклонённые» нет нигде
в DOM страницы (`document.querySelectorAll('*')` — поиск по всем узлам,
включая скрытые, ничего не находит). Фильтры не реализованы на UI вообще
— пользователь не может отфильтровать свои отзывы по статусу.

Согласуется с ранее найденным BUG-020/BUG-022 — вся страница «Отзывы»,
судя по всему, реализована как статичный демо-макет, не подключённый к
реальному контракту API (`filters[]`, `reviews[]`, `meta`), поэтому и
сами фильтры не были реализованы.

## Скриншоты

См. `screenshots/bug020-my-reviews-tab-hardcoded.png` — над списком
отзывов нет ни одного элемента фильтрации, сразу идут карточки.

## Вероятная причина

UI для фильтров, судя по всему, не реализован (или реализован, но скрыт
багом вёрстки) — вероятно, тот же корень, что и BUG-020: страница не была
доведена до подключения к реальному API-контракту.

## Автотест, фиксирующий баг

`cypress/e2e/Regress_Test/cabinet/reviews.cy.js` — тест ожидает 4 фильтра
на вкладке «Мои отзывы» и падает, пока баг не исправлен.
