# Баги, найденные при тестировании раздела «Отзывы» (/cabinet/reviews/)

Дата: 2026-08-07
Стенд: `http://d2.im.mdev.kz/` (тестовый), API `http://api.d.im.mdev.kz`

| ID | Название | Severity | Статус |
|---|---|---|---|
| [BUG-021](./BUG-021-page-naming-inconsistent.md) | Крошка «Мои отзывы» vs заголовок/меню «Отзывы» (тот же класс, что BUG-018) | Low | Подтверждён |

Нумерация продолжает `../coupons/` (BUG-017..019) — единая
последовательность в рамках раздела «Личный кабинет».

## Обновление 2026-08-10 — раздел значительно переработан разработчиками

Раздел «Отзывы» был перестроен на новый API-контракт: вместо `GET
/v2/reviews/waiting-products` + `GET /v2/reviews/personal` теперь всего
один эндпоинт `GET /v3/personal/reviews` (`{reviews, meta, summary}`).
BUG-020, BUG-022, BUG-027 (см. ниже, исправлены) относились к старой
реализации.

## Отклонено как не баг (файл удалён)

- **BUG-023** («Фильтры «Опубликованные»/«Отклонённые»/«На модерации» на
  вкладке «Мои отзывы» не отрисованы вообще», Jira AS-4527) — изначально
  заведён из-за старого контракта `v2/reviews/personal`, у которого было
  поле `filters[]`; у нового `v3/personal/reviews` этого поля нет вовсе.
  Подтверждено пользователем 2026-08-10 по дизайн-макетам («5. Отзывы» /
  «7. Отзывы»): на вкладке «Мои отзывы» предусмотрены только табы
  «Оставить отзыв»/«Мои отзывы», без под-фильтров по статусу — они не
  реализованы НЕ по ошибке, а никогда не были в дизайне и не будут
  добавлены. Тикет переведён в «Не актуален», файл удалён, тест на 4
  фильтра убран из `reviews.cy.js`.

## Исправленные баги (файлы удалены)

- **BUG-020** («ВСЯ страница «Отзывы» показывает захардкоженные данные»,
  Jira AS-4524) — исправлен, подтверждено 2026-08-10: оба таба теперь
  показывают РЕАЛЬНЫЕ данные — вкладка «Оставить отзыв» показывает товары
  из реальной истории покупок (напр. «Обогреватель BALLU BOH/EX-11» —
  подтверждённо совпадает с товаром из `bonuses-history`), вкладка «Мои
  отзывы» корректно показывает пустое состояние «Закажите и оставьте
  отзыв!» (у аккаунта реально 0 отзывов). Старый фейковый товар «Смарт-часы
  Huawei Watch GT 5 Pro Titanium» полностью исчез. Тикет переведён в
  «Готово», файл удалён.
- **BUG-022** («Блок статистики «60 Отзывов...» не построить из API»,
  Jira AS-4526) — исправлен, подтверждено 2026-08-10: блок теперь
  показывает «0 отзывов | 0 лайков | 0 просмотров», что точно совпадает с
  новым полем `summary.{publishedCount,likesCount,accruedBonusAmount}` в
  `GET /v3/personal/reviews`. Тикет переведён в «Готово», файл удалён.
- **BUG-027** («500-ошибка от waiting-products роняет всю страницу»,
  Jira AS-4532) — исправлен, подтверждено 2026-08-10: при подменённом 500
  для `/v3/personal/reviews` (замена старого `waiting-products` после
  переработки) страница продолжает рендериться — `<h1>`, хлебные крошки,
  боковое меню на месте. Тикет переведён в «Готово», файл удалён.
