# Баги, найденные при тестировании раздела «Отзывы» (/cabinet/reviews/)

Дата: 2026-08-07
Стенд: `http://d2.im.mdev.kz/` (тестовый), API `http://api.d.im.mdev.kz`

| ID | Название | Severity | Статус |
|---|---|---|---|
| [BUG-020](./BUG-020-hardcoded-review-cards-no-api-call.md) | ВСЯ страница «Отзывы» (обе вкладки) показывает захардкоженные данные — ни один реальный API-запрос не отправляется | **Critical (P1)** | Подтверждён |
| [BUG-023](./BUG-023-filters-not-rendered.md) | Фильтры «Опубликованные»/«Отклонённые»/«На модерации» на вкладке «Мои отзывы» не отрисованы вообще | Medium | Подтверждён |
| [BUG-022](./BUG-022-stats-block-source-unknown.md) | Блок «60 Отзывов \| 0 Лайков \| 0 Просмотров» не может быть построен ни из одного реального API-ответа (вероятно тот же корень, что и BUG-020) | High | Подтверждён |
| [BUG-021](./BUG-021-page-naming-inconsistent.md) | Крошка «Мои отзывы» vs заголовок/меню «Отзывы» (тот же класс, что BUG-018) | Low | Подтверждён |
| [BUG-027](./BUG-027-500-error-blanks-entire-page.md) | 500-ошибка от `waiting-products` роняет ВСЮ страницу «Отзывы» (тот же паттерн, что BUG-003 на `/cabinet/`) | High | Подтверждён |

Нумерация продолжает `../coupons/` (BUG-017..019) — единая
последовательность в рамках раздела «Личный кабинет».

**Это самый серьёзный раздел за всю сессию** — BUG-020 обнаружен как
критический (P1): пользователю показываются полностью вымышленные данные
(карточки товара, который он не покупал, и баннер с несуществующим
бонусом) без единого реального обращения к бэкенду.
