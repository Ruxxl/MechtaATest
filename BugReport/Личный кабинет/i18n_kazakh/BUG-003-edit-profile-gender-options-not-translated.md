# BUG-003: На казахской локали опции пола в редактировании профиля остаются на русском

**Раздел:** Личный кабинет — Редактирование профиля (модалка «Деректерді өңдеу»)
**Severity:** Medium
**Приоритет:** Medium
**Статус:** Подтверждён
**Дата:** 2026-08-17
**Окружение:** `http://d2.im.mdev.kz/kk/`, любая страница ЛК с доступом к панели
профиля, аккаунт John Appleseed

## Предусловия

Переключить сайт на казахский язык, авторизоваться, открыть панель редактирования
профиля (клик по имени/аватару в карточке профиля ЛК).

## Шаги воспроизведения

1. Переключить язык сайта на казахский.
2. Открыть любую страницу ЛК, кликнуть на имя/аватар пользователя — откроется модалка
   «Деректерді өңдеу».
3. Осмотреть значение и выпадающий список поля пола.

## Ожидаемый результат

Все подписи полей и значения в модалке редактирования профиля должны быть на казахском —
по аналогии с остальными полями («Атын енгізіңіз», «Тегін енгізіңіз», «Туған күні»,
«Есептік деректер», «Контактілер», «Сақтау» — всё переведено корректно).

## Фактический результат

Сама модалка и подписи всех текстовых полей переведены корректно, но **значение и обе
опции выпадающего списка пола остаются на русском**:

- Текущее выбранное значение в закрытом состоянии поля: «Мужской»
- При раскрытии списка — обе опции: «Мужской» и «Женский»

`screenshots/bug-edit-profile-gender-untranslated.jpg`

## Вероятная причина

Опции селекта пола («Мужской»/«Женский»), судя по всему, захардкожены как константы (или
приходят с бэкенда без учёта локали) и не проходят через общий механизм локализации,
которым переведены остальные подписи формы.

## Автотест, фиксирующий баг

`cypress/e2e/regress_test/lk_regress.cy.js` → `REGR-LK-008: переключение на казахский
язык — весь текст ЛК переведён, без «утечек» русских строк`.
