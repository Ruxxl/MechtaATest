# BUG-002: На казахской локали пустое состояние «Купоны» полностью на русском

**Раздел:** Личный кабинет — Купоны (`/kk/cabinet/coupons/`)
**Severity:** Medium
**Приоритет:** Medium
**Статус:** Подтверждён
**Дата:** 2026-08-17
**Окружение:** `http://d2.im.mdev.kz/kk/cabinet/coupons/`, аккаунт John Appleseed (0 купонов
на обеих вкладках на момент проверки)

## Предусловия

Переключить сайт на казахский язык, авторизоваться под аккаунтом без купонов (или
любым — пустое состояние отображается на любой вкладке при отсутствии элементов).

## Шаги воспроизведения

1. Переключить язык сайта на казахский.
2. Перейти в «Жеке кабинет» → «Купондар».
3. Осмотреть содержимое вкладки «Белсенді» (Активные) при пустом списке.
4. Переключиться на вкладку «Аяқталды» (Использованные), также с пустым списком.

## Ожидаемый результат

Заголовок страницы, вкладки и весь текст (включая пустое состояние) — на казахском.

## Фактический результат

Заголовок «Купондар» и названия вкладок «Белсенді»/«Аяқталды» переведены корректно, но
**весь блок пустого состояния остаётся на русском** на ОБЕИХ вкладках:

- «Нет доступных купонов» (заголовок)
- «Здесь будут купоны которые вы сможете применить при оформлении» (подзаголовок)

Не единичный сбой — воспроизведено идентично на обеих вкладках («Активные» и
«Использованные»), то есть это один переиспользуемый компонент пустого состояния, для
которого казахский перевод вообще отсутствует.

## Скриншоты

`screenshots/bug-coupons-empty-state-untranslated.jpg`

## Вероятная причина

Компонент пустого состояния купонов, вероятно, использует захардкоженные русские строки
напрямую в разметке, а не ключи из словаря переводов — в отличие от заголовка страницы и
вкладок, которые корректно переведены.

## Автотест, фиксирующий баг

`cypress/e2e/regress_test/lk_regress.cy.js` → `REGR-LK-008: переключение на казахский
язык — весь текст ЛК переведён, без «утечек» русских строк`.
