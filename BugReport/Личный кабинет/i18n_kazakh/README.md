# Баги, найденные при проверке казахской локализации ЛК

Дата: 2026-08-17
Стенд: `http://d2.im.mdev.kz/` (тестовый), переключатель языка «Ру»/«Кк» в шапке
(URL получает префикс `/kk/`)

Проверка по прямому запросу пользователя: пройтись по каждой странице ЛК с включённым
казахским языком и убедиться, что весь текст переведён. Полностью переведены и БЕЗ
замечаний: обзорная `/kk/cabinet/`, «Мои заказы», «Мои карты» (список), «Отзывы» (обе
вкладки), «Избранное» (`/kk/favorites/`), «Сравнение» (`/kk/compare/`). Найдено 3
локальных дефекта — см. таблицу ниже.

## Открытые баги

| Баг | Название | Severity | Статус |
|---|---|---|---|
| [BUG-001](./BUG-001-bonuses-offline-order-label-not-translated.md) | «Бонусы и фишки»: ярлык «Оффлайн заказ» не переведён | Low | Подтверждён |
| [BUG-002](./BUG-002-coupons-empty-state-not-translated.md) | «Купоны»: весь текст пустого состояния (обе вкладки) не переведён | Medium | Подтверждён |
| [BUG-003](./BUG-003-edit-profile-gender-options-not-translated.md) | Редактирование профиля: опции пола «Мужской»/«Женский» не переведены | Medium | Подтверждён |

Каждый баг зафиксирован одним общим автотестом в
`cypress/e2e/regress_test/lk_regress.cy.js` → `REGR-LK-008` — тест целенаправленно
проверяет отсутствие русских строк на казахской локали и падает по каждому из трёх
пунктов, пока баги не исправлены.
