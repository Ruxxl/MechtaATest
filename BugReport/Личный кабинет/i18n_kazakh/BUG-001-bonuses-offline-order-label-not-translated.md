# BUG-001: На казахской локали ярлык «Оффлайн заказ» в истории бонусов остаётся на русском

**Раздел:** Личный кабинет — Бонусы и фишки (`/kk/cabinet/bonuses/`)
**Severity:** Low
**Приоритет:** Low
**Статус:** Подтверждён
**Дата:** 2026-08-17
**Окружение:** `http://d2.im.mdev.kz/kk/cabinet/bonuses/`, аккаунт John Appleseed

## Предусловия

Переключить сайт на казахский язык (кнопка «Ру»/«Кк» в шапке), авторизоваться, открыть
раздел «Бонустар мен фишкалар». У аккаунта есть хотя бы одна операция с типом «оффлайн
заказ» (списание/начисление не по онлайн-заказу).

## Шаги воспроизведения

1. Переключить язык сайта на казахский.
2. Перейти в «Жеке кабинет» → «Бонустар мен фишкалар».
3. Осмотреть карточки операций.

## Ожидаемый результат

Весь текстовый интерфейс страницы, включая ярлык типа операции, должен быть на казахском
языке — по аналогии с остальными карточками («Тапсырыс №...», «тамызда», «Мәліметтерді
көрсету», «бонус»/«фишка» — всё это переведено корректно).

## Фактический результат

Карточка операции без привязки к конкретному онлайн-заказу показывает ярлык **«Оффлайн
заказ»** на русском языке, в то время как все соседние карточки и весь остальной текст
страницы — на казахском («Тапсырыс №10396114», «17 тамызда», «Мәліметтерді көрсету» и
т.д.). Единственная непереведённая строка на странице.

## Скриншоты

`screenshots/bug-bonuses-offline-order-untranslated.jpg`

## Вероятная причина

Строка-лейбл для типа операции «оффлайн заказ», по всей видимости, захардкожена на
русском на бэкенде/фронтенде и не участвует в общем механизме локализации (в отличие от
остальных строк страницы, подгружаемых из словаря переводов).

## Автотест, фиксирующий баг

`cypress/e2e/regress_test/lk_regress.cy.js` → `REGR-LK-008: переключение на казахский
язык — весь текст ЛК переведён, без «утечек» русских строк`.
