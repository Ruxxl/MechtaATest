# BUG-019: На странице «Купоны» пункт бокового меню «Купоны» НЕ подсвечен как активный

**Раздел:** Личный кабинет — Купоны (`/cabinet/coupons/`), боковое меню
**Severity:** Medium
**Приоритет:** Medium
**Статус:** Подтверждён
**Дата обнаружения:** 2026-08-07
**Окружение:** `http://d2.im.mdev.kz/cabinet/coupons/` (тестовый стенд d2)

## Предусловия

Пользователь авторизован, находится на `/cabinet/coupons/`.

## Шаги воспроизведения

1. Открыть `/cabinet/coupons/`.
2. Проверить визуальное состояние пункта бокового меню «Купоны».
3. Сравнить с поведением на других страницах раздела (`/cabinet/orders/`,
   `/cabinet/bonuses/`, `/cabinet/cards/`), где текущий пункт получает
   видимый серый фон.

## Ожидаемый результат

Согласно TC-КУ-2/TC-КУ-3, пункт меню, соответствующий текущей открытой
странице, должен иметь тёмный/выделенный фон — на всех 9 страницах раздела
подсвечен ровно один пункт. Уже подтверждено (сессия 2026-08-07), что этот
механизм корректно работает на `/cabinet/orders/`, `/cabinet/bonuses/`,
`/cabinet/cards/`.

## Фактический результат

На `/cabinet/coupons/` пункт «Купоны» визуально ничем не отличается от
остальных пунктов меню — обычный прозрачный фон
(`getComputedStyle(...).backgroundColor === 'rgba(0, 0, 0, 0)'`), тот же,
что у неактивных пунктов «Мои заказы», «Бонусы и фишки» и т.д. Ни один
пункт меню на этой странице визуально не выделен как текущий — пользователь
не может понять, в каком разделе он находится, глядя только на боковое
меню.

## Скриншоты

Скриншот страницы «Купоны»: боковое меню — все 7 пунктов (включая «Купоны»)
выглядят абсолютно одинаково, без какого-либо выделения текущего раздела.

## Вероятная причина

Логика подсветки активного пункта меню, реализованная для других
вложенных страниц (сверка текущего пути с `href` пункта), либо не
подключена для маршрута `/cabinet/coupons/`, либо сверяет путь с неверным
эталонным значением специально для этой страницы.

## Автотест, фиксирующий баг

`cypress/e2e/main_test/cabinet/coupons.cy.js` — тест проверяет
непрозрачный фон у пункта «Купоны» и падает, пока баг не исправлен.
