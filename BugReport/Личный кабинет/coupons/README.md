# Баги, найденные при тестировании раздела «Купоны» (/cabinet/coupons/)

Дата: 2026-08-07
Стенд: `http://d2.im.mdev.kz/` (тестовый), API `http://api.d.im.mdev.kz`

| ID | Название | Severity | Статус |
|---|---|---|---|
| [BUG-018](./BUG-018-page-naming-inconsistent.md) | Одна страница называется по-разному в 4 местах: «Мои купоны» (крошка/вкладка) vs «Купоны» (заголовок/меню) | Low | Подтверждён |
| [BUG-017](./BUG-017-title-is-h2-not-h1.md) | Заголовок «Купоны» — `<h2>`, не `<h1>` (четвёртый вариант системной проблемы, см. BUG-008/013/015) | Low | Подтверждён |
| [BUG-019](./BUG-019-sidebar-active-highlight-missing.md) | Пункт бокового меню «Купоны» вообще не подсвечивается как активный (в отличие от всех остальных проверенных страниц раздела) | Medium | Подтверждён |

Нумерация продолжает `../cards/` (BUG-015, BUG-016) — единая
последовательность в рамках раздела «Личный кабинет».

## Что НЕ было протестировано (и почему)

- **Структура карточки купона при непустом списке (TC-КУ-13..16)** — на
  тестовом аккаунте нет ни активных, ни использованных купонов
  (`GET /v3/personal/promo-codes` возвращает `[]` для обоих `filterBy`).
  Сам тест-план прямо помечает этот раздел как «ТРЕБУЕТСЯ ПРИМЕР» — без
  реального ответа с непустыми данными нельзя достоверно проверить поля
  карточки (код, скидка, срок действия и т.п.). Оставлено для будущей
  сессии, когда появится тестовый аккаунт/мок с реальными купонами.
