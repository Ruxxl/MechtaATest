# Баги, найденные при тестировании раздела «Мои карты» (/cabinet/cards/)

Дата: 2026-08-07
Стенд: `http://d2.im.mdev.kz/` (тестовый), API `http://api.d.im.mdev.kz`

| ID | Название | Severity | Статус |
|---|---|---|---|
| [BUG-016](./BUG-016-add-card-button-does-nothing.md) | Клик «Добавить карту» открывает модалку с полностью пустым содержимым (zoid-iframe без src) | High | Подтверждён |
| [BUG-015](./BUG-015-page-title-hidden-on-desktop.md) | `<h1>` «Мои карты» существует, но скрыт на десктопе (`lg:hidden!`) — третий вариант системной проблемы с заголовками (см. BUG-008, BUG-013) | Low | Подтверждён |

Нумерация продолжает `../bonuses/` (BUG-010..014) — единая
последовательность в рамках раздела «Личный кабинет».

## Что НЕ было протестировано (и почему)

- **Реальное удаление карты (TC-МО-9, TC-МО-10, TC-МО-11)** — на аккаунте
  ровно одна сохранённая карта, а кнопка «Добавить карту» не работает
  (BUG-016), поэтому реальное удаление необратимо лишило бы будущие
  тест-сессии единственной тестовой карты. Проверено только открытие
  диалога подтверждения и отмена (карта остаётся на месте).
- **Успешное добавление карты через реальный ввод данных (TC-МО-22..25)**
  — не выполняется принципиально: правила безопасности прямо запрещают
  ввод номеров карт/CVC в любые поля, включая тестовые/фиктивные данные.
  К тому же форма всё равно не грузится (BUG-016), так что физически
  нечего заполнять.
- **Лимит на количество карт (TC-МО-25)** — не проверено, требует
  добавления множества карт, что невозможно из-за BUG-016.
