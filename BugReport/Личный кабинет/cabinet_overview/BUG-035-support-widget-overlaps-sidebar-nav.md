# BUG-035: Плавающая кнопка чата поддержки перекрывает и блокирует клики по иконкам «Купоны»/«Отзывы» в сайдбаре ЛК

**Раздел:** Личный кабинет — общий сайдбар навигации (любая страница `/cabinet/*`)
**Severity:** Medium
**Приоритет:** Medium
**Статус:** Подтверждён
**Дата:** 2026-08-20
**Окружение:** `https://pp.yc.mechta.kz/`, viewport 1560×830 (высота контента ≈656px —
типичная высота для ноутбучных экранов 1366×768/1440×900 с панелью браузера)

## Предусловия

Авторизованный пользователь, любая страница `/cabinet/*`, окно браузера с невысоким
viewport (сайдбар из 8 пунктов меню не помещается настолько, чтобы нижние пункты
оказались там же, где зафиксирована плавающая кнопка чата поддержки — левый нижний
угол экрана).

## Шаги воспроизведения

1. Открыть `/cabinet/orders/` (или любую другую `/cabinet/*`) в окне с ограниченной
   высотой видимой области — воспроизведено двумя независимыми способами:
   а) реальный resize окна браузера до ~1560×830 (видимая область контента ≈656px)
      — типичная высота для ноутбучных экранов 1366×768/1440×900 с панелью браузера;
   б) `document.documentElement.style.zoom = 1.6` на полноразмерном окне — тот же
      эффект «сайдбар не помещается над кнопкой чата», использовано для чистых
      скриншотов ниже.
2. Обратить внимание на пункты сайдбара («Купоны»/«Отзывы» при способе (а),
   «Личный кабинет»/«Бонусы и фишки»/«Мои карты» при способе (б) — конкретные пункты
   зависят от того, насколько сильно сдвинулась геометрия) — на их иконках лежит
   круглая розовая кнопка чата поддержки.
3. Кликнуть точно по перекрытой иконке.

## Ожидаемый результат

Кнопка чата поддержки не должна перекрывать интерактивные элементы страницы; клик по
иконке пункта меню должен вести на соответствующую страницу, как и клик по тексту
пункта.

## Фактический результат

- Иконки «Купоны» и «Отзывы» в сайдбаре полностью визуально скрыты под круглой кнопкой
  чата — вместо иконок пользователь видит просто розовый кружок.
- Клик по этой области (там, где должна быть иконка) **не открывает** соответствующий
  раздел ЛК — вместо этого раскрывается виджет чата поддержки (появляются кнопки
  звонка/Telegram/закрыть), перекрывая ещё больше пунктов меню.
- Клик по тексту названия пункта («Купоны»/«Отзывы», правее иконки, не под кнопкой
  чата) по-прежнему работает и ведёт на нужную страницу — то есть баг не блокирует
  навигацию полностью, но иконки нефункциональны и невидимы в этой зоне.

## Вероятная причина

Кнопка чата поддержки зафиксирована в левом нижнем углу окна (`position: fixed`) без
учёта фактической высоты контента страницы под ней — на страницах с длинным
вертикальным сайдбаром (все `/cabinet/*`) при недостаточной высоте viewport она
попадает поверх нижних пунктов меню вместо пустого пространства под ними.
