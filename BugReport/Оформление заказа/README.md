# Баги, найденные при сквозном тестировании оформления заказа (чекаут)

Дата: 2026-08-12
Стенд: `http://d5.im.mdev.kz/` (тестовый), API `http://api.d5.im.mdev.kz`

Проверялись: оплата картой (новый эквайринг test-epay.epayment.kz / Halyk), способы
доставки (бесплатная/платная Астана, самовывоз из разных магазинов, экспресс-доставка,
смена города), товары с подарком, списание бонусов, промокоды.

| ID | Название | Severity | Статус |
|---|---|---|---|
| [BUG-001](./BUG-001-promocode-persists-across-unrelated-carts.md) | Промокод/купон, применённый один раз, навсегда «прилипает» к аккаунту и автоматически применяется к любым новым, не связанным с ним корзинам | Medium | Подтверждён |

## Что НЕ было оформлено как баг (и почему)

- **Расхождение суммы в модалке подтверждения заказа (174 019 ₸) и на странице эквайера
  (164 019 ₸)** при заказе с подарками + списанием бонусов (заказ №5513, 2026-08-12) —
  при точном повторе того же сценария (тот же товар, те же подарки, тот же промокод)
  суммы полностью совпали на каждом шаге (заказ №5515). Разовая гонка/сбой пересчёта,
  не воспроизводится стабильно — не баг.
- **Группа подарков «Внешний аккумулятор Infinix XP03 White»** есть в API
  (`gifts` товара, 3-я группа), но не отображается в модалке выбора подарка на сайте
  (только 2 из 3 групп) — воспроизведено дважды на товаре Infinix Note 50, стабильно.
  По решению пользователя не заведено как баг в рамках этой сессии.
- **На новом аккаунте бонусы блокируются требованием «Завершите регистрацию»**, хотя
  реально начислены и видны на странице «Бонусы». По решению пользователя не заведено
  как баг в рамках этой сессии.
- **`GET /v2/personal` отдаёт `bonus_info.active: 0`**, пока реальный баланс на UI
  (страница «Бонусы», чекаут) корректный — рассинхрон эндпоинтов. По решению
  пользователя не заведено как баг в рамках этой сессии.
