# BUG-001: «Скрыть витрину» на товаре, где ВСЕ магазины витринные, даёт пустой список без сообщения и без обновления счётчика

**Раздел:** Страница товара — блок «Доступно на самовывоз» (`onlyShopwindow`)
**Severity:** Low
**Приоритет:** Low
**Статус:** Подтверждён
**Дата обнаружения:** 2026-08-04
**Окружение:** `https://pp.yc.mechta.kz/product/kondicioner-arayplus-fm-07hrn8-s-installyaciey/`

## Предусловия

Товар, у которого **все без исключения** магазины в `GET /api/v3/product/{slug}/subdivisions`
имеют `onlyShopwindow: true` (то есть доступны только «на витрине», без обычного
остатка) — подтверждено: для этого товара все 7 записей имеют `onlyShopwindow: true`
и `stock: "На витрине"`.

## Шаги воспроизведения

1. Открыть страницу товара.
2. Прокрутить до блока «Доступно на самовывоз (7 магазинов)».
3. Включить чекбокс «Скрыть витрину».

## Ожидаемый результат

Один из вариантов корректной обработки:
- Заголовок блока обновляется до реального количества оставшихся (не витринных)
  магазинов — «Доступно на самовывоз (0 магазинов)», **или**
- Под таблицей показывается явное сообщение вида «Нет магазинов без товара на
  витрине» / «По вашему выбору ничего не найдено».

В любом случае пользователь должен понимать, что список пуст осознанно, а не решить,
что страница не догрузилась.

## Фактический результат

Таблица под чекбоксом становится полностью пустой (только заголовки колонок «Адрес» /
«В наличии», ни одной строки), при этом:
- Заголовок блока продолжает показывать **старое** значение — «Доступно на самовывоз
  (7 магазинов)» — не пересчитывается после фильтрации;
- Никакого текста вроде «не найдено» не появляется — пустая таблица выглядит как
  незагрузившийся или сломанный блок, а не как осознанно пустой результат фильтра.

Воспроизведено стабильно (checkbox переключался туда-обратно несколько раз, поведение
идентичное).

## Скриншоты

- `screenshots/bug001-hide-shopwindow-empty-list-stale-count.jpg` — заголовок

## Вероятная причина

Похоже, что счётчик в заголовке блока считается один раз при первой загрузке данных
(`subdivisions.length`) и не пересчитывается при клиентской фильтрации по чекбоксу
«Скрыть витрину», а сама таблица при этом полноценно фильтруется — рассинхрон между
двумя частями одного и того же виджета, обе из которых должны отражать один и тот же
набор данных.
