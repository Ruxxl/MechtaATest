`cypress/e2e/Regress_Test/product_page/product_onlyShopwindow/` (BUG-001) или
`cypress/e2e/Regress_Test/product_page/cart_crosssell.cy.js` (BUG-002) или

`cypress/e2e/Regress_Test/product_page/reviews.cy.js` (BUG-005) — тест целенаправленно
ожидает правильное поведение и падает, пока баг не исправлен.

## Что НЕ было оформлено как баг (и почему)

- **`inStock` (smartfon-apple-iphone-15-128gb-pink) тоже имеет `onlyShopwindow: true`.**
  Обнаружено при подборе fixture-товаров для этой области — сначала выглядело как
  несостыковка (fixture называется «inStock», но товар витринный), но это не баг: поле
  `onlyShopwindow` не противоречит наличию товара, оно лишь означает способ получения
  (только самовывоз с витрины конкретного магазина). Задокументировано в
  `cypress/fixtures/products.json`.
- **TC-BONUS-02/03 (переход по ссылке «Подробнее» из подсказки бонусов, ошибка
  недоступного роута) — этой функциональности на сайте физически нет.** Подсказка
  (`[role="dialog"]`, заголовок «Программа лояльности»), открывающаяся кликом по строке
  «+N бонусов, +N фишек», содержит только текст и безымянную кнопку закрытия — ни ссылки,
  ни кнопки «Подробнее» внутри неё нет. План описывает функциональность, которой не
  существует в реализации — не баг (не сломанная ссылка, а отсутствующая), задокументировано
  в `cypress/e2e/Regress_Test/product_page/bonus_info.cy.js`.
- **TC-BANNER-01..06 (баннер акции на странице товара) — этой функциональности на
  сайте физически нет.** Проверено на 2 товарах с непустым `promotions[]` в
  `/api/v3/product/{slug}` (`naushniki-apple-airpods-4-mxp63zea` — 2 промо,
  `smartfon-samsung-galaxy-z-flip8-5g-256gb-pink` — 2 промо): 0 изображений с
  `storage.mechta.kz` на странице, 0 ссылок на `/useful/shares/`, 0 элементов с
  `promo` в className — баннер нигде не рендерится, хотя данные о промо-акциях
  реально приходят с бэка. Как и TC-BONUS-02/03, план описывает функциональность,
  которой нет в текущей реализации — не баг (не сломанный баннер, а отсутствующий).
- **TC-REV-04 (кнопка «Показать все отзывы» / пагинация) — этой функциональности на
  сайте физически нет.** Товар с `totalPages: 2` в ответе `/reviews` (наушники
  AirPods 4, 7 отзывов, `perPage: 6`) на странице показывает ровно первые 6 и НЕ
  предлагает никакого способа увидеть 7-й — ни кнопки «Показать все»/«Показать ещё»,
  ни номеров страниц, нигде в тексте страницы. API поддерживает пагинацию, но UI её
  не использует — не баг (не сломанная пагинация, а её отсутствие в разметке).
- **Связь «Новый ↔ Уценённый» (группа `type: "defective"` в `/similar`) односторонняя.**
  У «Новый»-варианта в `/similar` есть группа с альтернативой-«Уценённый»; но у самого
  «Уценённого»-варианта в ЕГО `/similar` этой группы нет вообще — нет пути назад к
  «Новому» тем же виджетом. Подтверждено напрямую через API (не предположение) — не баг,
  так пришли данные с бэка, задокументировано в `variant_selector.cy.js`.
